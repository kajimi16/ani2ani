# ani2ani

(๑•̀ㅂ•́)و✧ 欢迎来到 ani2ani～

一个「打开链接就能一起看动漫」的方案 (´｡• ᵕ •｡`) ♡
不用装客户端，不用注册账号，浏览器打开就是放映厅～

## ✧ 它偷偷在做什么

服务器先把片子切成一小块一小块 HLS 分片 (•̀ᴗ•́)و，然后大家用 WebRTC 互相递块块，服务器只掏第一份 (๑>؂<๑)。找朋友这件事交给自带的 tracker 和 STUN，全程不出校园网 ✧

## ✧ 一起看的时候

进度条听房主的 (｀・ω・´)。想回看精彩片段就自己拉，拉完点一下「对齐到房主」就回来了 ヽ(•̀ω•́ )ゝ弹幕从画面上飘过去，边看边吐槽 (っ˘ω˘ς )

## ✧ 一点点小心思

私密房间要密码进门，连分片都认密码哦 (๑•̀ㅁ•́๑)✧转码、排队、磁盘够不够，都是它自己在操心 (´-ω-`)
